Open. Upload. Explore.

  1. Photos lein: car ke gird ek direction mein 12–24 photos lein. Car poori frame mein rakhein.
  2. Upload karein: photos filename ke order mein aayengi. Thumbnail select karke Move earlier / Move later se order change karein.
  3. View dekhein: photo par left/right drag karein, ya arrow buttons, keyboard aur slider use karein. Play se sequence chalegi.
  4. Poora chakkar? Kam az kam 12 photos hon aur poori car ka chakkar cover ho to 360 looping ka checkbox tick karein.
  5. Copy rakhein: Save HTML copy se photos wali file save karein. Kisi Chrome/Edge browser mein double-click karke khol lein.

Browser storage isi browser/profile par hoti hai; clear karne se photos hat sakti hain. Saved HTML copy mein photos rehti hain. Display photos ko 1600px tak resize kiya jata hai, taake space kam lage.
