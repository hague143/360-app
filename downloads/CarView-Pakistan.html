Photos or video. Every angle.

  1. Photos: car ke gird ek direction mein 36–72 clear photos lein. Upload photos se select karein. Filenames ke order mein view banega; Move earlier / Move later se order theek karein.
  2. Video: parked car ke gird ek poora chakkar record karein, takreeban 20–60 seconds. Video tab se file select karein. Preview mein start/end time set karein, 36 / 72 / 120 frames choose karke Create photo view dabayein. MP4 (H.264) sab se zyada compatible hai; doosre formats browser support par depend karte hain.
  3. Rotate: Rotate car mode mein ek ungli se drag karein. Arrows, keyboard ya slider se bhi angle badalta hai.
  4. Inspect: do ungliyon se pinch, mouse wheel, + button ya double-click se zoom karein. Inspect details mein drag karke mirror, doors ya lights dekhein. Zoom rakh kar angle badalne ke liye Rotate car ya slider use karein. Fit car / keyboard 0 se reset hota hai.
  5. Poora chakkar: sequence ka order aur coverage check karein. 12+ frames hon aur ek full lap cover ho to Enable 360 looping tick karein. Video import khud coverage verify nahi karta.
  6. Save: Save HTML copy se photos/frames aur details wali file save karein. Dobara Chrome/Edge mein double-click se khol sakte hain; original video ki zaroorat nahi hogi.

Normal quality 1600px tak display copies banati hai. More detail ke liye import se pehle 2560px choose karein. Zoom source photo/video ki available detail dikhata hai. Steady camera, clear focus aur similar distance se result behtar hota hai.

Browser storage isi profile par hoti hai; clear karne se photos hat sakti hain. Saved HTML copy mein frames rehti hain. Yeh captured angles ka interactive photo viewer hai; unseen sides ya freely movable 3D scene generate nahi hota.
