`neon-hero.png` is a legacy AI-generated decorative concept-studio illustration created with OpenAI image_gen for the earlier lime/cyan UI. It is not a listing photograph, a real vehicle identity or condition evidence. The original PNG is preserved without pixel edits, but is no longer included or required by the current build.

The current purple/pink home hero uses only locally selected photographs through `../hero-photos.js`. The procedural vehicle has been removed. No Lexus photographs, recoloured photos or generated replacement angles are bundled in the empty distribution. Selecting photos and saving an app copy embeds the checked display copies in that HTML. Actual ad media remains separate from the decorative home showcase.
