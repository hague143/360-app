CARVIEW PAKISTAN - CAR ADS + 360 VIEW
===================================
1. ZIP ko Extract All karein.
2. CarView-Pakistan-Marketplace.html double-click karke Chrome/Edge mein kholein.
3. Sell your car par click karein.

NEON SHOWROOM UI
----------------
Purple/pink UI aur aapka uploaded Koenigsegg Agera 3D model included hai.
HTML kholte hi model apne aap rotate karta hai. Body pearl white hai.
Mouse/finger drag se orbit; do ungliyon ka pinch ya mouse wheel se zoom.
+ / - buttons, Pause/Rotate aur Reset view controls bhi hain. 0 reset karta hai.
Yeh supplied 3D display model hai; seller ki asli car/condition ka saboot nahi.

Home wala Photo angles / Choose Lexus photos / Arrange photos option hata diya.
Ab home box hamesha supplied 3D model dikhata hai. Purani saved photo setting
bhi nayi copy mein model kholti hai; saved car ads/media delete nahi hoti.
Landing background mein purple/pink studio lighting aur decorative car artwork
hai. Text/buttons readable hain; background ad form/inspection mein nahi aata.
Save app copy se poori app aur existing ads wali portable HTML save karein.

Model HTML mein embedded hai; alag ZIP, textures, Blender, Node ya internet nahi
chahiye. Browser 3D support na de to isi model ki static preview nazar aati hai.
Reduced-motion setting mein automatic rotation pause rehti hai.

AD BANANE KE 5 STEPS
-------------------
1. City, area, make, model, year aur optional variant.
2. Registration, mileage, colour, fuel, transmission, assembly, engine,
   price, features aur car ki description.
3. Normal ad photos, original video (50 MB tak) aur aapka original 360 studio.
   Video preview aur published ad mein Video tab par chalegi. Studio se
   selected original video bhi save hoti hai (50 MB tak). Us mein pehle ki tarah
   photos ya video use karein, pinch zoom aur Inspect details chalayein.
   Purani saved 360 HTML file ho to Use saved 360 HTML par select karein.
4. Seller name, Pakistani mobile number, private seller/dealer aur WhatsApp.
5. Buyer preview check karke Save to showroom dabayein.

EXPLORE CARS
------------
Is browser ke showroom mein saved ads nazar aayengi. City, make, price,
year, fuel, transmission aur mileage se search/filter kar sakte hain.
Ad khol kar tamam photos/frames, original Video tab, 360 view, specs,
features, seller description aur
phone/WhatsApp buttons check karein.

MY ADS
------
Draft continue/edit, preview, mark sold aur delete yahan se karein.
Listed ad edit karne par draft banta hai; review ke baad showroom mein
dobara save karein. Sold ads Explore cars se hat jati hain.

SAVE / SHARE
------------
Normal browser mein data isi device/profile par auto-save hota hai.
Private mode ya blocked/full browser storage ho to status message dekhein.
Download this ad se ek HTML file mein us ad ki photos, 360 aur contact
details save hoti hain. Is copy ko doosre computer par bhi khol sakte hain.
My ads > Download backup se tamam drafts/ads/photos/contacts ki copy banti hai.
Shared copy mein contact number aur notes bhi shamil hote hain.

Node.js, account, installation ya internet nahi chahiye.
Google sign-in is version mein add nahi kiya gaya.
Yeh local test marketplace hai: ad PakWheels ya kisi public website par
post nahi hoti. Doosre log tab dekhte hain jab aap HTML copy share karte hain.
Public multi-user hosting aur account verification baad mein configure honge.

ORIGINAL 360 FEATURE
--------------------
Original studio file aur uske video/gesture code ko change nahi kiya gaya.
Naya listing flow usi studio ko embedded module ke taur par use karta hai.
Studio ka Save HTML copy button standalone 360 HTML bhi save karta hai.
Video: MP4 (H.264) recommended, max 500 MB/3 minutes. 36/72/120 frames.
Rotate car = drag. Pinch/wheel/+ = zoom. Inspect details = drag to pan.
Fit car = poori car dobara frame mein. Other formats browser par depend hain.

Is release mein koi actual ad, real phone number ya user-uploaded video
include nahi hai. Images aap khud select karte hain.
